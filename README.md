# TimeTrack · 网页浏览时间统计

> 看清你的浏览时间都花在哪里：自动记录、纯本地保存、注重隐私。数据只保存在本机，不上传、无账号、无后端。

## 这是什么

一个 Chrome / Chromium（Edge 等）Manifest V3 扩展，在后台安静地记录：

- 今天浏览器的**活跃总时长**
- 每个**网站（domain）**用了多久、占比多少、访问次数
- 与昨天相比的变化
- 当前正在浏览的网站
- 网站 Top 排行（popup 展示前 5）
- 侧边栏 Dashboard：Today / 最近 7 天 / 最近 30 天切换、日期前后翻页、日均、活跃站数、最常用网站、每日柱状趋势图，以及按时长/次数/字母排序的完整网站排行

只统计「窗口聚焦 + 当前激活标签页 + 用户未离开（idle 阈值内）」三者同时成立的时间，最小化后台标签页、最小化窗口、挂机离开等场景的误计。

## 安装（开发者模式加载）

1. 打开 Chrome，地址栏输入 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本项目的**根目录**（包含 `manifest.json` 的 `count-web-time` 文件夹）。
5. 工具栏出现 TimeTrack 图标即安装成功；建议点拼图图标把它固定到工具栏。

无需 `npm install`、无需构建：扩展直接运行仓库里的原生 JS。

## 使用

- 正常浏览即可，计时全自动。
- 点击工具栏图标打开 popup：今日总时长、环比昨天、当前网站、Top 5 网站，每 2 秒自动刷新。
- 点击 popup 底部的 **View detailed analytics**，在浏览器侧边栏打开完整 Dashboard，可切换 Today / 7 Days / 30 Days 并前后翻页查看历史：每日柱状趋势图、**网站分布环形图**（Top 5 + 其他，图例与扇区联动）、按时长/次数/字母排序的完整网站排行；图表支持 hover 显示具体日期与时长。
- 点击排行中的任意网站进入**单站详情**：四区间汇总、平均会话、近 30 天**每日活动折线图**、最近会话列表，返回按钮回到列表。
- popup 与 Dashboard 右上角的齿轮按钮打开**设置页**：空闲超时（30s/60s/2 分钟/5 分钟）、是否追踪媒体播放与隐身窗口、主题（跟随系统/浅色/深色）、数据导出/导入备份、清除今日数据 / 清除全部数据（危险操作有确认弹窗）。
- 界面语言自动跟随浏览器：内置**简体中文**与 English，中文系统显示中文（时长显示为「1小时42分」、日期为「8月31日」），无需手动切换。

## 计时规则

| 场景 | 行为 |
|---|---|
| 切换标签页 | 结束旧网站计时，开始新网站计时 |
| 同一网站内跳转不同页面 | 合并到同一个 domain（仅 `www.` 会被剥离） |
| `www.example.com` 与 `example.com` | 合并为 `example.com` |
| `mail.google.com` 与 `drive.google.com` | **保持独立**，不做强制合并 |
| 浏览器窗口失焦 / 最小化 | 暂停计时，重新聚焦后续计 |
| 超过空闲阈值（默认 60 秒，可在设置页改为 30 秒/2 分钟/5 分钟） | 自动暂停，重新操作后续计 |
| 刷新页面 | 计时连续，不产生异常累计 |
| 跨午夜仍在使用 | 按本地 0 点拆分到两天 |
| `chrome://`、`edge://`、`about:`、`file://` 等特殊页面 | 不统计，静默处理 |

计时基于事件时间戳差值（tab 激活、窗口焦点、导航、idle 状态），**不使用 `setInterval` 每秒累加**；状态切换时立即落库，另有 30 秒一次的兜底保存，因此即使浏览器的 service worker 被回收也不会丢时间。

## 手动验收清单（加载后建议走一遍）

1. 打开任意普通网站停留约 15 秒 → 点图标，总时长约为 15 秒。
2. 打开第二个网站的标签页并切换 → 两个网站分别累计、互不干扰。
3. 切到其他软件让浏览器失焦约 30 秒 → 该期间时长不增加。
4. 停住不动超过 60 秒 → 自动暂停；移动鼠标/按键后继续。
5. 在当前页面按 F5 刷新 → 时间连续、没有跳变或重复计数。
6. 在同一网站内点不同链接 → 仍归到同一 domain；导航到别的域名 → 分开统计。
7. 关闭当前标签页 → 该网站时间被正确结算。
8. 完全退出并重新打开浏览器 → 之前的数据仍然存在。

查看底层数据：在 `chrome://extensions` 点击 TimeTrack 卡片上的 **Service Worker** 打开控制台，执行：

```js
chrome.storage.local.get(null, (d) => console.log(d));
```

清空全部本地数据：

```js
chrome.storage.local.clear();
```

（数据可视化操作：在设置页可导出 JSON 备份、导入恢复、清除今日或全部数据。）

## 权限说明（最小权限原则）

| 权限 | 用途 |
|---|---|
| `storage` | 统计数据保存在 `chrome.storage.local`，纯本地 |
| `tabs` | 获取当前活动标签页的 URL 以识别 domain，并监听切换/导航/关闭 |
| `idle` | 按设置的空闲阈值（默认 60 秒）检测无操作，自动暂停 |
| `alarms` | 30 秒周期兜底持久化 |
| `favicon` | 通过浏览器本地的 `chrome://favicon` 显示网站图标，不发起网络请求，失败时回退为首字母占位 |
| `sidePanel` | 在侧边栏打开完整 Dashboard |

**没有**申请 `<all_urls>` / host 权限，**不注入** content script，**没有**远程脚本与任何网络请求。

## 隐私

- 默认不联网、不上传 URL 与浏览记录、无分析 SDK、无云同步、无账号。
- 统计只到 domain 粒度，不保存完整 URL 与页面标题。
- 数据仅存在本机浏览器 profile 中，卸载扩展即随之删除。

## 目录结构

```text
count-web-time/
├── manifest.json        # MV3 清单
├── background.js        # service worker：Chrome 事件 → 计时状态机
├── tracker.js           # 计时状态机（纯逻辑，可离线测试）
├── storage.js           # chrome.storage.local 数据层
├── utils.js             # 域名归一化 / 日期 / 时长格式化（支持中英文）
├── i18n.js              # 界面语言辅助（跟随浏览器语言）
├── theme.js             # 主题应用（system/light/dark → <html data-theme>）
├── charts.js            # Dashboard 图表渲染（柱状 / Donut / 折线 + tooltip）
├── _locales/            # 语言包：zh_CN（简体中文）/ en（English）
├── popup.html/js/.css   # 工具栏弹窗（今日概览）
├── dashboard.html/js/.css # 侧边栏 Dashboard（区间统计、趋势、单站详情）
└── settings.html/js/.css  # 设置页（计时/主题/数据/隐私）
```

## 已知限制

- 不统计特殊页面（设计如此）。隐身窗口默认不统计，可在设置页开启「追踪隐身窗口」——但需先在 `chrome://extensions` 的扩展详情里勾选「允许在隐身模式下运行」，否则 Chrome 不会把隐身窗口暴露给扩展。
- 「追踪媒体播放」以页面是否发声（`audible`）判定：有声音播放时失焦/空闲不暂停；静音播放的视频不在此列。
- 正式打包上架后 Chrome 把 alarm 最小周期限制为 1 分钟（开发者模式为 30 秒）；只影响兜底频率，不影响准确性，关键切换始终即时保存。
- 网站图标直接读浏览器本地 favicon 缓存，浏览器无缓存时回退为首字母占位。
